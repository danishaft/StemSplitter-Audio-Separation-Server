# Project agent instructions

Read [`DESIGN.md`](./DESIGN.md) before creating or changing any user-facing
interface. Its tokens and prose are the normative design contract. Update the
contract before introducing a new color, type role, spacing value, radius,
shadow, component state, or page-composition pattern.

Use [`docs/design/design-system.md`](./docs/design/design-system.md) for product
context and [`docs/design/public-platform-ui-case-studies.md`](./docs/design/public-platform-ui-case-studies.md)
for competitive rationale. When those documents conflict with `DESIGN.md`, use
`DESIGN.md` and correct the stale document in the same change.

Verify presentation changes at 1440px, 1024px, 390px, and 320px. Preserve the
functional splitter, keyboard access, touch targets, reduced motion, and honest
capability states.
